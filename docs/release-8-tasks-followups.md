# Release 8: Tasks, Lead Follow-ups & SLA Management Engine

## 1. Executive Summary

Release 8 implements a high-performance, multi-tenant Task Management and Lead Follow-up Engine for the **flumenxConectOS** internal marketing operations platform. Building directly on the CRM foundation (Releases 1–7), Release 8 guarantees that inbound leads captured from Meta Ads, Google Ads, Elementor forms, and custom webhooks receive immediate operational follow-up within strict Service Level Agreement (SLA) response windows.

## 3. Data Models & Schemas

### 3.1 Task (`Task.ts`)
* `clientId`: ObjectId referencing Client workspace (strictly tenant-isolated).
* `title`: Follow-up title (e.g. `Inbound Lead Follow-up: Jane Doe`).
* `description`: Rich context including lead contact info and intake notes.
* `taskType`: `call`, `email`, `meeting`, `follow_up`, `review`, `other`.
* `status`: `open`, `in_progress`, `completed`, `cancelled`, `snoozed`.
* `priority`: `low`, `normal`, `high`, `urgent`.
* `dueAt`: Operational due timestamp.
* `slaDeadline`: Computed SLA target timestamp.
* `slaTargetMinutes`: Target response duration in minutes (e.g. 15, 60, 240, 1440).
* `slaBreached`: Boolean indicating whether response target window was exceeded.
* `slaBreachedAt`: Timestamp when breach occurred.
* `assignedTo`: ObjectId referencing active `User` belonging to workspace.
* `completedBy`: ObjectId referencing user who completed task.
* `completedAt`: Completion timestamp.
* `completionNotes`: Staff closure notes.
* `disposition`: Outcome code (e.g. `contacted`, `rescheduled`, `left_voicemail`).
* `isAutoGenerated`: Boolean flag identifying automated pipeline triggers.
* `idempotencyKey`: Unique deduplication key (`lead_followup_${clientId}_${leadId}`).
* **Compound Indexes**:
  * `{ clientId: 1, status: 1, dueAt: 1 }`
  * `{ clientId: 1, assignedTo: 1, status: 1 }`
  * `{ clientId: 1, priority: 1, dueAt: 1 }`
  * `{ clientId: 1, slaBreached: 1, slaDeadline: 1 }`
  * `{ clientId: 1, idempotencyKey: 1 }` with `{ unique: true, partialFilterExpression: { idempotencyKey: { $type: "string" } } }`

### 3.2 TaskEvent (`TaskEvent.ts`)
Immutable audit trail recording every state change and assignment mutation:
* `taskId`, `clientId`, `eventType` (`created`, `assigned`, `reassigned`, `priority_changed`, `due_date_changed`, `status_changed`, `snoozed`, `disposition_applied`, `sla_breached`, `completed`, `cancelled`).
* `actorId`, `actorName`: Audit accountability.
* `previousValue`, `newValue`: Before and after diffs.

### 3.3 TaskDisposition (`TaskDisposition.ts`)
Standard outcome library seeded per workspace or globally:
* `contacted`: Customer reached and conversation initiated.
* `left_voicemail`: Voicemail recorded; next follow-up recommended.
* `rescheduled`: Customer requested call back at another time; auto-schedules next task.
* `qualified`: Lead confirmed suitable for proposal.
* `unqualified`: Lead does not meet criteria.
* `not_interested`: Prospect declined service.
* `wrong_number`: Invalid phone/contact info.
* `no_response`: Prospect did not answer.

### 3.4 SlaPolicy (`SlaPolicy.ts`)
Configurable response targets per workspace:
* `urgentTargetMinutes`: Default 15 minutes.
* `highTargetMinutes`: Default 60 minutes (1 hour).
* `normalTargetMinutes`: Default 240 minutes (4 hours).
* `lowTargetMinutes`: Default 1440 minutes (24 hours).
* `businessHoursOnly`: Flag for business calendar evaluation.
* `escalationEmail`: Notification contact for breached tasks.

## 5. Security & Multi-Tenancy Guarantees

* **Tenant Isolation**: Every task query strictly scopes to `clientId`. Cross-client requests return `404 Not Found`.
* **RBAC Enforcement**: Staff members cannot assign tasks (`tasks.assign` restricted to Admin/SuperAdmin) or modify SLA targets (`tasks.manage_sla` restricted).
* **Assignee Validation**: The `TaskAssignmentService` verifies that an assigned user possesses both `User.status: 'active'` AND an active `ClientMembership` record in the target workspace. Assigning tasks to suspended staff or non-members is strictly rejected with `400 Bad Request`.
